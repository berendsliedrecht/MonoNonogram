# MonoNonogram

Randomly generated nonogram (picture logic) puzzles for the Mudita Kompakt (e-ink), built with the Mudita Mindful Design (MMD) framework. Pick a grid size (5x5, 8x8 or 10x10), tap to fill or pencil-mark cells, no timer on screen, no guessing: puzzles are generated by rejection sampling, keeping a random grid only if the line-logic solver completes it, which also guarantees a unique solution. Solves are timed quietly; a stats screen tracks games solved and the fastest solve per size. Progress is saved per size. Fully offline.

## Install

```
./gradlew installDebug
```

Or sideload the release APK from `app/build/outputs/apk/release/` (debug-signed on purpose so it installs directly).

## Structure

- `Puzzles.kt`: puzzle model and clue derivation
- `Solver.kt`: line-logic solver and the random puzzle generator built on it
- `NonogramViewModel.kt`: board state, undo, win detection, solve timing and persisted progress
- `ui/HomeScreen.kt`: grid size buttons and the stats entry
- `ui/BoardScreen.kt`: clue and grid canvas, fill/mark tools, undo, a toggle that crosses out finished lines, and a board menu (bottom sheet) with clear and new puzzle
- `ui/StatsScreen.kt`: games solved and fastest solve per size

`PuzzleSolvabilityTest` checks clue derivation, rejects an ambiguous puzzle, and asserts generated puzzles at every size are solvable with line logic alone.
